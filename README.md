
## Class 3: Synthetic Multi-Well Pressure Surveillance
Records from inactive sensors (`WELL-09`, `WELL-12`) and invalid readings (`None` or negative pressures on `WELL-11` and `WELL-13`) are skipped using `continue` so they do not distort active well averages. A function `return` value sends a computed result back to the caller for reuse in further calculations, whereas `print()` only displays text on the screen.
